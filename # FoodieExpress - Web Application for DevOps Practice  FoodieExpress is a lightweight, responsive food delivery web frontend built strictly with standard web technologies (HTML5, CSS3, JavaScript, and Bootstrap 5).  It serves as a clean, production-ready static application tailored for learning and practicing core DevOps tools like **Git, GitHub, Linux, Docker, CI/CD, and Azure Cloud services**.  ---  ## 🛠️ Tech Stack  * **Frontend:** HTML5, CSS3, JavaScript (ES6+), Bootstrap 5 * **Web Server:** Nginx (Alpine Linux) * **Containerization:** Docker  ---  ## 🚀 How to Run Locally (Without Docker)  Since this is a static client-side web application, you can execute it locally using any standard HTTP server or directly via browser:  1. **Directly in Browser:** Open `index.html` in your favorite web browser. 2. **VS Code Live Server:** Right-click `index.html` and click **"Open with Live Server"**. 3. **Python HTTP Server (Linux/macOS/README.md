# FoodieExpress - Web Application for DevOps Practice

FoodieExpress is a lightweight, responsive food delivery web frontend built strictly with standard web technologies (HTML5, CSS3, JavaScript, and Bootstrap 5).

It serves as a clean, production-ready static application tailored for learning and practicing core DevOps tools like **Git, GitHub, Linux, Docker, CI/CD, and Azure Cloud services**.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5
* **Web Server:** Nginx (Alpine Linux)
* **Containerization:** Docker

---

## 🚀 How to Run Locally (Without Docker)

Since this is a static client-side web application, you can execute it locally using any standard HTTP server or directly via browser:

1. **Directly in Browser:** Open `index.html` in your favorite web browser.
2. **VS Code Live Server:** Right-click `index.html` and click **"Open with Live Server"**.
3. **Python HTTP Server (Linux/macOS/Windows Terminal):**
   ```bash
   python3 -m http.server 8000
